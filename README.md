# ✨ WriteWise

An AI-powered writing assistant built with Streamlit and Hugging Face. WriteWise helps users improve their writing through grammar correction, readability analysis, sentiment analysis, paraphrasing, summarization, and intelligent writing suggestions.

---

## 🚀 Features

* Grammar correction
* Spelling correction
* Punctuation correction
* Corrected text generation
* Sentiment analysis
* Readability analysis
* Writing suggestions
* Text statistics
* AI-powered paraphrasing
* AI-powered summarization

---

## 🛠 Tech Stack

* Python
* Streamlit
* LanguageTool
* TextBlob
* TextStat
* Hugging Face Inference API

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/smhbaani/WriteWise.git
```

Move into the project folder:

```bash
cd WriteWise
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
